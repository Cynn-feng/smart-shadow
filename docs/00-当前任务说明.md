5. **阶段 5：可复现部署**。补依赖、迁移、readiness、结构化日志和恢复演练。

阶段 7 是研究并行线，不改变阶段 1–5 的业务开发门；阶段 6 必须等阶段 1–5 验收后再启动。这样编号与 [04-实施方案](04-实施方案.md) 保持一致，后续 agent 不应把“阶段 7 已有契约切片”理解成主业务已经进入阶段 6。

当前阶段 7 的真实图片契约切片已落地：`model_adapter.py`、`real_image_runner.py` 和 `eval/pc_scft_real_image_eval.py` 先用 `source-residual-v1` 打通了私有图片的解码、哈希、配对和 raw evidence 回放。当前下一步是准备真实授权 `real_pc_scft_manifest_v1`、独立 ordinary-propagation null profile 和编辑 mask；没有授权、独立 null profile 和完整配对时，继续输出 `unauthorized_input`、`insufficient` 或 `review`，不输出 AIGC 概率。该切片不接旧线上服务。

最新区域选择切片 `regional_fdr.py` 已把逐区域 null p-value 与 BH q-value 选择接入离线 runner；`candidate_regions` 只用于人工 ROI 复核，不代表正式 FDR 保证或 AIGC 结论。

最近新增的 MPCF 研究切片 `aigc/mpcf.py` 将 SCTE/PC-SCFT 的目标区域 delta 与同资产、同 pair、同传播族、同质量桶、同 detector/schema 的 matched placebo controls 对照，计算 ties-inclusive finite-sample p-value、control median、contrast 和 spread。`candidate_edit` 与 `control_consistent` 只属于 raw evidence 路由；控制样本身份、质量、来源匹配或支持数不足时固定 `insufficient`。该切片不接线上服务，不输出 AIGC 概率、四态结果、作者身份或法律结论。

最近新增的 Source-Conditioned Crop-Consensus 研究切片 `aigc/crop_consensus.py` 将同一登记原件/observed/counterfactual pair 的多 crop view 绑定到 canonical coordinate frame，以质量×来源匹配加权的正向 view 比例、区域集合 overlap 和 ordinary-propagation crop-null p-value 形成 `consensus_candidate`、`null_consistent`、`view_inconsistent` 或 `insufficient`。它只保存 raw evidence，不改写 `aigc_result_v1` 或线上服务；质量桶、身份、坐标帧、detector/schema、view/null 支持不足时必须拒判。

最近新增的 7.9 切片是 `patch_contribution`：对 patch coverage 结果执行逐 patch leave-one-out 和 top-k mask-out，用于发现显眼 patch/语义边界造成的 forensic distraction。它只输出 raw review evidence；真实 edit mask、传播 hard negative、跨生成器和时间切分仍未验证。

最近新增的研究切片是 `real_manifold_profile.py`（ONMA）和 `scte.py`（SCTE）：前者提供版本化 real-only natural-manifold raw fallback，后者把 observed/counterfactual 区域三元证据严格绑定后接入 regional FDR。两者都只属于阶段 7 离线研究，不能改写 `aigc_result_v1` 或接入比赛版线上服务。

最近新增的 `edit_lineage.py` 是有序操作链审计切片：内容编辑必须同时具备步骤 `mask_digest` 与区域 `mask_overlap_raw`，普通传播步骤可无编辑 mask 但结果显式标记 `operation_scope=ordinary_propagation`，只用于 hard-negative/null 证据。`lineage_consistent` 只代表 trace 与 raw evidence 契约一致，不代表 AIGC、来源或作者结论。

最新有序轨迹切片 `aigc/lineage_view_control.py` 已完成离线契约：复用已绑定的 `EditLineageTrace`、多个 canonical view 的 observed/counterfactual delta 和上游 MPCF control summary，审计 view persistence、跨视角离散度与 step onset order。它不重新拟合 placebo、不接模型或线上服务；`consistent_controlled_lineage`、`trajectory_inconsistent` 和 `insufficient` 都只是 raw evidence 路由，真实授权过程、mask、独立控制集和正式 FPR/coverage-risk 仍待验证。
