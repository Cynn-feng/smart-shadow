## 使用规则

- **A 级**：法律法规、国家/国际标准、政府/法院/标准组织原文，或正式发表的会议论文/官方评测计划。
- **B 级**：官方产品文档、公开 benchmark/数据集页面、正式 workshop 论文或组织方说明。
- **C 级**：预印本、厂商宣传、市场文章或二手解读，只能作为线索，不能单独支撑合规或算法效果结论。
- `核验日` 表示本次调研检查链接和版本的日期，不表示项目已经实现或验证了来源中的能力。
- `可迁移主张` 只说明它能约束本项目的设计或实验；禁止把来源指标、客户数量、价格和合规结论直接外推到 Smart Shadow。

## 最小可辩护创新边界

上述来源已经覆盖“成对编辑定位、重建差分、质量加权、失真拒判、开放集检测、传播评测、生成器归因和来源凭证”等单项组件。当前项目只有在 A0–A8 消融、授权图片、时间/生成器隔离和真实传播评测完成后，才可检验下面的组合主张：

> 同一登记资产、同一传播变换下的 query/counterfactual 区域证据检验，叠加区域配准、质量/传播族 null 校准和证据不足拒判。

该组合目前仍是研究假设。索引中的论文支持实验设计和重合排除，不支持 Smart Shadow 已有准确率、开放集保证、法律结论或商业收入。每条主张进入 README、论文或产品材料前，都必须关联一个可复现 runner、数据 manifest digest 和 `docs/07-验证与运行记录.md` 中的真实结果。

### 路线重合审计（供 `docs/06` 和 `docs/04` 引用）

- **SCTE/PC-SCFT**：原图—编辑图、CLIP+mask、局部变化和差分都有公开先例；可辩护的最小差异是登记原件、同传播族 ordinary-propagation counterfactual、质量/区域分层 null 和拒判回放的共同评测，不能把差分或 ROI 单独命名为创新。
- **ONMA**：natural-manifold、real-only、on-manifold hard negative、prototype 和 continual adaptation 均有 prior art；项目只可检验“无原件 fallback + 有权限时 latent hard negative + 版本化适配/回滚”的组合控制面。
- **BMEA**：DACOM、likelihood-ratio selective classification、QuAD 已覆盖可检测性、选择函数和质量聚合；项目需要把完整 probe policy、预算、失败状态和策略级重校准纳入同一 null 回放，才能讨论工程组合增量。
- **Provenance/水印**：C2PA、IAR provenance、InvisMark、对象级水印和用户级水印分别覆盖声明绑定、模型来源、生成端水印和用户归因；必须分开保存 `generator_binding`、`user_binding`、`training_data_influence`、passive evidence，任何一层都不能覆盖四态拒判。

因此，索引支持的唯一后续组合假设是：有登记原件且传播族可覆盖时，SCTE/PC-SCFT 经 detectability gate、group-matched conformal/BH 和完整 BMEA 策略校准后，是否相对 A0/A1/A2 降低普通传播误报与 selective risk；无原件或未知生成器时，ONMA 是否只提升拒判质量而不把阴性变成人类结论。该假设必须关联冻结授权 manifest 和运行记录后才能升级。
