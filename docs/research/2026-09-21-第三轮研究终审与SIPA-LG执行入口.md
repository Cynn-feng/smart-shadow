# 第三轮研究终审与 SIPA-LG 执行入口

更新时间：2026-09-21

本文件把本轮论文、标准、市场和算法审计收敛成后续 Agent 可以执行的单一入口。它是研究输入，不替代
`docs/01` 的决策事实、`docs/02` 的仓库事实或 `docs/07` 的运行记录。

## 终审结论

没有发现一篇工作同时闭环以下链路：登记原件条件、普通传播 matched null、检索 winner 固定、时间/删除
生命周期、开放集拒判、局部干预和反取证压力。因此 Smart Shadow 的可辩护白区仍然是一个可回放的审计协议，
不是另一个单图 detector。

但完整 CFAEA 目前还不能直接编码。当前 ALG-001 只有单一 A archive/replay，TLEG 还没有接入 retrieval replay，
也没有真实 B direct-lookup holdout、独立 null 或 generator registry。先写完整 CFAEA 会把字段契约误当成算法
结果。因此研究顺序收窄为：

```text
SS-001 主业务无假成功
  → SS-032 真实 archive/index preparation 与 G0–G6
  → SIPA-LG-v1：A replay → TLEG-A → freeze winner/region
                    → B direct lookup → TLEG-B → B ordinary-null
  → 条件性接入 CFAEA 的 generator registry/cross-fit
  → 只有真实压力脆弱性成立时才评审 AR-SCMI
```

## SIPA-LG-v1 最小协议

SIPA-LG 是 SS-020 的首个可编码子协议，必须先于完整 CFAEA。它不改 `aigc_result_v1`，不输出概率，不接
比赛版服务或客户数据。

### A 侧选择与生命周期

ALG-001 A 回放生成候选 rank、membership、传播树、selection trace 和 winner。TLEG-A 校验
`query_as_of`、`snapshot_created_at`、ledger/index head、删除墓碑、恢复新版本、授权/留存/访问 digest、
tenant、split 和 time window。A 侧通过后才可冻结不可变的 `winner_id`、`tree_id`、`region_proposal_digest`、
canonical frame、operator 和 action budget。

### B 侧 holdout 与 matched null

B 只能对冻结 winner/region 做 direct lookup，禁止返回 top-K、重排、改 region、换 operator 或重拟合 null。
B 至少需要两条独立性轴（推荐三条）：archive/time、feature/index build、query view/operator/evidence stream。
B 侧再用同 transform × quality × transport × time × source-match 分层的 ordinary-propagation null 计算 raw rank/
contrast，TLEG-B 再次校验生命周期。B 缺失、过期、删除或没有 direct-lookup 证明时，不能回退 A 的结果。

### 固定 raw route

`holdout_consistent`、`holdout_disagreement`、`missing_holdout`、`selection_contaminated`、
`ordinary_propagation_consistent`、`open_set_unknown`、`insufficient`、`not_evaluated`。

`p_B_raw`、方向一致性和 contrast 只是审计 raw evidence；A/B 的 p-value 不相乘、不合并为概率。普通传播、
unknown、冲突和生命周期失败永远不能升级为 candidate。

## SS-032 数据准备门

在有真实授权数据以前，SS-032 只允许提交 schema、validator 和 fixture。必须冻结：

- 授权原件、普通传播版本、局部编辑、wrong-reference/decoy 和删除/恢复事件；
- A/B archive/index snapshot、candidate rank、membership、tree、selection trace；
- asset/group、时间、生成器、传播和 transport 的互斥 split；
- snapshot/index/archive/event/evidence digest、访问审计、留存规则、删除墓碑和回显策略；
- 两次独立回放命令及完全一致的摘要 digest。

G0–G6 逐门对应权限、普通传播 null、局部编辑 mask、开放集/误配、分层外部切分、同预算对照和证据包复核。
缺任一门只能保持 `not_evaluated`、`insufficient` 或 `review`，不得写 FPR、coverage-risk、ROI、P95 或
“算法已证实”。

## 条件性后续

SIPA-LG 的真实结果若显示来源证据在 JPEG、resize、截图、再数字化或授权压力下出现可重复脆弱性，再批准
AR-SCMI-v1。AR-SCMI 仍是压力审计 sidecar，不是新 detector；若 CFAEA/PC-SCFT 没有暴露可重复脆弱性，
下一步应修复 archive/lifecycle/replay 和 SS-001，而不是继续堆叠 AIGC 模块。
