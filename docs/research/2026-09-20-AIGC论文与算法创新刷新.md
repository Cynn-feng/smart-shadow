# 2026-09-20 AIGC 论文与算法创新刷新

更新时间：2026-09-20
证据范围：2024–2026 年公开论文原文、正式会议页面、作者/官方代码仓库。
用途：给 Smart Shadow 的阶段 7 研究线提供 prior-art 审计、可证伪的下一切片和 G0–G6 实验门。

本文不是论文结果，也不是产品能力声明。论文和外部代码的指标只用于决定对照、数据切分和失败边界；它们不构成 Smart Shadow 的准确率、概率、部署、客户或法律证据。

## 1. 结论先行

最近两年的证据把问题边界推得更清楚：单图二分类器在跨生成器、跨语义、社交平台传播、局部编辑和新时间窗上都会出现性能跌落；开放世界、定位、校准和不确定性已经成为独立评测轴。局部编辑检测也已经出现“给定原图与可疑图”的直接先例，因而 Smart Shadow 不能把“原件+查询图”本身包装成首创。

Smart Shadow 仍有一条可检验的差异，但它是**协议组合假设**，不是已经证明的新基础模型：

> 在有授权登记原件的版权工作流中，将 observed query、同传播族 ordinary-propagation null、blind decoy/wrong-reference 和多视角/多 operator 反事实放到同一个 canonical frame 与 evidence digest 下；先用 source-conditioned matched intervention 得到局部差异，再用独立的 open-set/real-only 路由和拒判门决定是否进入人工复核。

这条主张只有在“去掉 null/control 后风险或复核成本显著变差、加入 null/control 后在未见生成器和传播时间窗仍保持改善”时才成立。若收益只来自已知生成器、随机合成或额外拒判，应撤回为证据审计协议。

| 论文/官方代码 | 已覆盖的先例 | Smart Shadow 应采用的对照 | Smart Shadow 尚未拥有的差异 |
| --- | --- | --- | --- |
| [Your AI-Generated Image Detector Can Secretly Achieve SOTA Accuracy, If Calibrated，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/38146)；[作者代码](https://github.com/muliyangm/AIGI-Det-Calib) | 冻结 backbone，用少量目标域样本做 scalar logit correction，说明阈值漂移会伪装成泛化提升。 | 保存 calibration id/digest、目标域/时间窗、样本支持量、ECE/Brier 和回滚指针；禁止在 evaluation split 上调阈值。 | 标量后验校准不能替代 independent ordinary-propagation null、开放集拒判或来源绑定。 |
| [Diffusion Epistemic Uncertainty with Asymmetric Learning，ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Huang_Diffusion_Epistemic_Uncertainty_with_Asymmetric_Learning_for_Diffusion-Generated_Image_Detection_ICCV2025_paper.pdf) | 用 Laplace approximation 区分 diffusion reconstruction 的 epistemic/aleatoric uncertainty，并做不对称训练。 | 作为 slow-path reconstruction/uncertainty adapter；单独测计算成本、传播跌落和 OOD reject。 | uncertainty 仍是单图 detector 证据，不提供 source/query/null 的差分。 |

| [Conformal Classification with Equalized Coverage for Adaptively Selected Groups，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/c4bf73386022473a652a18941e9ea6f8-Abstract-Conference.html) | 研究按适应性选择群组后的 coverage；提示普通 conformal 在选择后需要额外处理。 | A9/BMEA 的多 probe 策略必须把整条 policy 当 calibration unit，报告 policy-FPR/coverage，而非把单 probe p-value 直接相乘。 | 通用 conformal 理论不是 Smart Shadow 的真实数据保证；交换性、组选择和 null 独立性要由 manifest 证明。 |

## 3. Prior-art audit：哪些内容已被覆盖

以下内容不能单独作为 Smart Shadow 的创新题目：

1. **只换一个 backbone 或多流拼接**：CLIP、pixel/entropy、频域、phase、DIRE、diffusion reconstruction、VLM/MLLM 和 semantic+pixel 融合均已有公开先例。
2. **只做 open-set / generator attribution**：OpenSDI、FSD、GAPL/LTD/RealStats 类工作已经覆盖开放世界检测、real-only 或来源归因；family top-1、nearest prototype、real-only energy 都不能单独称创新。
3. **只做局部 mask/热图/删除插入解释**：WACV 2024 定位、DICE、SIDA、DiffForensics、counterfactual explanation 和多个 segmentation benchmark 已覆盖。
4. **只做原图—编辑图差异**：EditTrack 已直接把 base/suspicious pair 作为 AI-assisted editing detection/attribution 问题；“有 reference”不是新颖性证据。
5. **只加水印、C2PA 或置信度**：ProMark、RAW、InvisMark、WMAR、C2PA 和 Authenticated Contradictions 已覆盖主动信号和冲突风险；水印/凭证阴性不能证明人类创作。
6. **只增加拒判或校准**：目标域 calibration、quality-aware calibration、Bayesian uncertainty 和 conformal 方法已有先例；拒判只有在固定人工预算下改善 selective risk 或人工成本，才是项目价值。
7. **只用 synthetic runner 的 AUROC/IoU/digest**：它们只能证明契约、确定性和 fixture，不证明真实图片、客户传播或论文效果。

## 4. 可继续验证的算法候选：SC-CET/CPED

### 4.1 候选名称与最小主张

暂定内部名称：**Source-Conditioned Causal-Inspired Evidence Test（SC-CET）**；代码切片可命名为 `causal_paired_delta_v1` 或 `CPED-v1`。这只是研究候选，不是新决策、不是已实现模块，也不是“解决 AIGC”。

可证伪主张：在同一登记原件和传播条件下，**observed—ordinary-null 的 matched intervention contrast** 应比 query-only、reference residual-only 或无 null 的方法更能降低普通传播误报，并在未见生成器/新时间窗下保持更高的 `risk@coverage` 和 ROI faithfulness。

“causal”只表示干预算子和 paired control 的设计灵感。除非有随机化干预与明确 SCM 假设，文档和论文统一使用 `causal-inspired` 或 `difference-in-differences-style`，不用“因果证明”。

### 4.2 四臂证据设计

每个 query 至少冻结以下四类输入：

| 臂 | 作用 | 失败含义 |
| --- | --- | --- |
| `reference` | 登记原件、版本 digest、canonical frame | 原件不可信或无权限时不能进行 source-conditioned 路由 |
| `observed` | 用户提交/传播后的 query | 只保存 raw detector 和区域证据 |
| `ordinary_propagation_null` | 从同一原件或 query 生成的裁剪、缩放、JPEG、截图、再拍摄等普通传播版本 | null 缺失、支持不足或质量/传播不匹配时固定 `insufficient` |
| `blind_decoy/wrong_reference` | 相似原件、随机原件和错误参考，测错误匹配造成的假局部差异 | decoy 未独立或与候选泄漏时固定 `review`，不能用来压低阈值 |

对每个 canonical view `v` 和预注册干预算子 `k`，先保留 raw intervention effect：

```text
I(x, r, M, v, k) = score(x, r, v) - score(maskout(x, M, v, k), r, v)

D_obs = I(observed, reference) - I(ordinary_null, reference)

D_decoy = median_d [ I(observed, decoy_d) - I(ordinary_null, decoy_d) ]

CPED = D_obs - D_decoy
```

上式只是一种预注册统计量。实现时必须保存每个 `I`、view、operator、region、null 和 decoy 的 digest，不得只保存最终 `CPED`。若只使用单个 decoy，不能称 median 或形成稳健分布；若 decoy 与候选共享选择样本，必须拆分 selection/evaluation。

推荐路由是 raw route：

```text
candidate_edit              # observed contrast 超过独立 null/control 门
null_consistent              # 普通传播 null 已解释 observed contrast
reference_ambiguous          # decoy/wrong-reference 也同样支持
view_or_operator_inconsistent# 多视角/多 operator 不稳定
open_set_or_provenance_review# family/provenance/watermark 冲突
insufficient                 # 缺权限、质量、null、mask、支持或 digest
```

这些路由不能映射成 AIGC 概率、`human_supported`、作者身份、版权归属或侵权结论。

### 4.3 与最接近先例的真实差异

| 先例 | 已解决 | SC-CET 仍要证明的不同问题 |
| --- | --- | --- |
| EditTrack | base/query 的 AI edit detection 与 attribution | 同传播族 ordinary null 是否能排除传播/配准伪影；错误 reference 是否触发 review；证据是否可回放 |
| OpenSDI/SIDA/SAFE | open-world、局部/整图检测、定位和社交传播 benchmark | 有权属登记原件时的 source-conditioned paired test；未知/证据冲突时主动拒判 |
| B-Free/Semi-Truths | 语义配对和局部增强数据 | 面向同一真实资产的传播反事实、版本图和客户权限；数据切分必须防止原件泄漏 |
| FSD/RealStats/DEUA | real-only/uncertainty/open-set 单图 detector | 无原件 fallback 只作 sidecar；不能覆盖有原件的 causal-inspired regional contrast |
| C2PA/水印/Authenticated Contradictions | 签名、软绑定、主动信号和跨层冲突 | 只把它们作为 evidence adapter；与 visual/reference contrast 冲突就 review，不让任一层单独定性 |

如果完整 SC-CET 与 `observed−ordinary-null` 消融没有差异，或只在 known-generator synthetic 集改善，应撤回“算法创新”，保留为 evidence packaging/人工复核排序。

## 5. 下一代码切片建议（仅研究轨，不立即改代码）

现有 `paired_delta_calibration.py`、`mpcf.py`、`counterfactual_mask_persistence.py`、`operator_stability.py`、`reference_specificity.py`、`evidence_graph.py` 已覆盖其中大部分原语；下一切片不应复制它们。建议新增一个很薄的组合契约：

| 项目 | 建议 |
| --- | --- |
| 模块 | `aigc/causal_paired_delta.py` |
| 测试 | `tests/test_causal_paired_delta.py` |
| runner | `eval/causal_paired_delta_eval.py` |
| 输入 | 已绑定的 reference/observed/null/decoy sidecar、canonical frame、mask/operator digest、profile/config/dataset digest |
| 计算 | 只做 deterministic difference-in-differences-style contrast、独立 control median/finite-sample p-value 和 fail-closed route；不调用模型、不训练、不改 `aigc_result_v1` |
| 必测失败 | selection/evaluation 泄漏、decoy 重复/不足、null/quality/transform 不匹配、operator route flip、ordinary propagation 误入 content-edit、缺输入 digest、metadata 含 probability |
| 验收 | 至少 12 项契约测试、≥6 个标量 fixture、`py_compile`、`git diff --check`、轻量验证；fixture 结果只写 raw route |
| 回滚 | 删除独占模块、测试、runner 和公共导出；不修改 PC-SCFT/MPCF/D-056 或线上接口 |

只有在真实授权 manifest 具备后才允许把这个薄组合层与 D-057 router 做同一实验；D-057 仍是独立候选，不应在 CPED 中把 family route 混成局部差异分数。

## 6. G0–G6 真实实验门

| 门 | 必须冻结/验证 | 通过条件 | 失败处理 |
| --- | --- | --- | --- |
| G0 权限与 manifest | 原件、版本、query、编辑 mask、传播链、C2PA/水印状态、生成器族/工具、时间窗、删除/留存责任和同意范围 | 每个输入可追溯到授权 manifest；selection/evaluation 和训练/校准/测试无资产泄漏 | 只允许 `insufficient`；不得用公开图拼出客户结果 |
| G1 ordinary-propagation null | JPEG、resize、crop、截图、再拍摄、平台多轮重编码及复合链；transform digest、质量桶、随机种子固定 | null 的支持量、质量和传播族独立；普通传播 FPR/route flip 有置信区间 | null 不足、支持污染或高 FPR 时撤回局部 AI 编辑主张 |
| G2 局部编辑 | inpaint/outpaint/img2img/AI upscale/人类+AI 混合；编辑 mask、操作 trace、生成器/工具和人工复核 | 未见编辑工具仍有记录；ROI/边界指标和 reference match 可回放 | 只保留 raw evidence，禁止映射 AIGC 四态 |
| G3 开放集与错误匹配 | leave-one-generator-out、same-family unseen、neural-rendering/AR unseen、相似 decoy、wrong-reference、provenance/watermark forgery | unknown recall、reference false-match、conflict review 和 family flip 均按预注册门报告 | 只提升 closed-set Recall@1 或错误归因增加时撤回为诊断 sidecar |
| G4 泛化、选择性和成本 | next-time-window、复合传播、质量/分辨率/裁剪/再拍摄、人工 review budget | ordinary FPR、risk@coverage、coverage、unknown/review、ECE/Brier、ROI、P50/P95、每千张成本和人工分钟同时改善或不恶化 | coverage-risk 或人工成本变差时不准扩大路由 |
| G5 消融与对照 | query-only、reference residual-only、无 null、无 decoy、无 canonical frame、单 operator、无 mask persistence、D-056/D-057/外部基线 | 完整 protocol 的增益必须在 paired asset bootstrap/置信区间下可见，且不是只增加拒判 | 若去掉 null/control 无性能跌落，撤回 source-conditioned 创新 |
| G6 回放与部署门 | 输入/输出 digest、profile/config 版本、失败原因、删除/恢复、重跑 determinism、结构化错误和权限越界 | 独立 reviewer 可从 manifest 重放；错误不会返回 success；成本/延迟和人工采用有记录 | 退回离线 fixture；不接 Go/AI 服务、不写产品 SLA |

G0–G6 的“通过”只代表对应层级通过。特别是 G0–G6 全部通过，也只能支持“在指定授权集和协议下的选择性研究结果”，不能推出通用 AIGC 检测、作者身份或法律事实。

## 7. 统计与报告模板

每个实验至少输出以下分层表，而不是单个总分：

| 维度 | 指标 |
| --- | --- |
| 普通传播安全性 | ordinary-propagation FPR、null mask hallucination、route flip、false activation outside mask |
| 选择性 | coverage、risk@coverage、unknown/review rate、finite-sample p-value、policy-FPR |
| 局部证据 | ROI IoU/Dice/boundary-F、pointing、mask-out faithfulness、region-swap contrast、step persistence |
| 来源/参考 | reference false-match、decoy exceedance、C2PA/watermark/visual conflict rate、family flip |
| 泛化 | leave-one-generator-out、same-family unseen、neural-rendering/AR unseen、next-time-window、质量/分辨率/传播分层跌落 |
| 运营 | P50/P95、显存/CPU、每千张成本、人工复核分钟、证据包一次采纳率、重放成功率 |

统计上使用资产级 bootstrap 或预注册配对检验；同一资产的多个 crop、operator、传播版本不能当作独立样本。所有阈值、alpha、最小支持量和停止门在查看测试结果前冻结。p-value 只说明相对冻结 null 的兼容性，不转换为 AIGC 概率。

## 8. 研究停止与回滚

满足任一条件就停止扩展模型，回滚到 raw evidence sidecar：

- 完整协议相对无 null/control 没有普通传播 FPR 或人工分钟改善；
- 只在已知生成器或随机 synthetic fixture 上改善，时间下一窗/未见生成器失效；
- unknown/review 率下降但 risk@coverage、错误参考或人工复核成本上升；
- 水印/C2PA 阴性被误写为人类创作，或 conflict 被静默融合；
- 任一输入无法由授权 manifest 重放，或失败路径返回 success；
- 新模块需要覆盖已有 D-050–D-057 的 profile/sidecar，造成历史 evidence 不可回放。

当前可对外使用的措辞仍应是“来源条件的局部证据研究协议”“可回放的拒判与人工复核工作台”。只有 G0–G6 和预注册消融通过后，才可在论文中讨论“source-conditioned selective edit forensics”；产品材料仍不得写成通用 AIGC 解决方案。
