# 2026-09-21 检索污染感知传播树选择校准

更新时间：2026-09-21（Asia/Shanghai）
证据范围：2024–2026 年正式会议论文、会议官方论文页、PMLR/JMLR/TMLR 官方页面和作者 arXiv 原文。
用途：在 PC-SCFT、SAEC、SAEA、SCPTN 已有切片之后，重新审计“真实传播检索不完整或被污染”这一缺口，并提出一个可以被真实数据证伪的下一算法切片。
状态：研究输入；没有真实图片、重量模型、生产阈值、AIGC 概率、部署或法律结论。

## 1. 先给可执行结论

当前最值得继续验证的方向是 **RSCPTN-v1（Retrieval- and Selection-Calibrated Source-Conditioned Propagation-Tree Null，检索与选择校准的来源条件传播树空模型）**。

它针对 SCPTN 尚未解决的真实世界问题：系统通常拿不到完整传播树，近重复检索会漏召回、误召回或被攻击者植入相似副本；如果先从检索结果中挑版本、再对局部差异做检验，SCPTN 的树内最大值校准仍不能解释检索事件本身造成的误报。QuAD/AncesTree 已经证明近重复质量融合有效，但把检索结果当作已给定输入，并把“漏召回、误召回和攻击性植入”列为未量化的开放问题。

RSCPTN 不再只校准一个已知树内的最大 paired local delta，而是把下列过程作为同一个预注册选择事件，在独立 ordinary-propagation placebo 上完整重放：

```text
near-duplicate retrieval
  → membership / tree assignment
  → reference and version selection
  → canonical-view/operator evidence
  → tree-level max local effect
```

最小差异是一个**双空模型**：

1. `p_tree_raw`：在已验证的 ordinary-propagation 树上，校准树内版本选择后的最大局部效应；它承接 SCPTN。
2. `p_retrieval_raw`：把 ordinary-propagation placebo 重新送入同一个检索器、候选数、排序、membership gate、树选择和 decoy 过程，校准“检索/选择本身制造的最高局部效应”；它补上 QuAD、SCPTN 和 SAEC 尚未覆盖的 end-to-end retrieval selection bias。
3. 只在两路都通过、检索完整性和开放集支持均足够时，输出 `retrieval_tree_candidate` 的 raw route；`max(p_tree_raw, p_retrieval_raw)` 只是保守的双门 raw gate，不是 AIGC 概率或统计保证。

这不是新的 detector、近重复聚合器、树模型或因果识别器。只有当同一授权 manifest、同一检索候选和同一动作预算下，RSCPTN 相对 SCPTN、SAEC、SAEA 和 QuAD-like baseline 降低 ordinary-propagation FPR、reference false-match 或人工复核分钟，并在漏召回、误召回、未知生成器和下一时间窗保持，才可以讨论研究增量。否则应保留为 retrieval/provenance audit sidecar。

## 2. 当前切片审计：缺口在哪里

| 现有切片 | 已解决的问题 | 仍然假设已知或未处理的量 |
| --- | --- | --- |
| PC-SCFT / SCTE / MPCF | 同登记原件、同 canonical frame、同 mask/operator 的 observed–counterfactual matched intervention；普通传播 null 和 placebo 对照 | query 已经正确绑定到 reference/null；不检验检索器是否漏掉或误召回近重复版本 |
| D-054 reference specificity | blind decoy/wrong-reference，控制相似错误原件被当作来源 | decoy pool 和候选 reference 已由检索器正确提供；不校准检索候选集合本身的选择事件 |
| D-058 invariant effect / D-051 operator stability | 多视角、多算子和跨视角 persistence 的稳定性 | 版本节点和 tree membership 已知；不处理未知 parent、漏分支、误合并和恶意近重复 |
| D-060 SAEC | 对从多个 reference/decoy 选择 winner 后的 max statistic 做选择后校准 | selection unit 是可枚举的 reference/decoy；没有把 retrieval recall、候选污染和 tree shape 一起纳入选择事件 |
| D-061 SAEA | 固定成本预算下根据失败原因追加 decoy、null、view、operator 或对齐 probe | 追加 probe 的输入候选来自可信检索；采集后 route 仍需要 end-to-end 重新校准 |
| D-062 SCPTN | 将同一登记资产的普通传播版本按树分组，以树为统计单位校准树内最大 paired delta | 传播树已经可靠重建；没有 retrieval contamination profile，也没有漏召回/误召回的独立 placebo 检验 |
| D-056 open-set routing | 无原件时的 family/real-only/open-set raw fallback | 未把“未知生成器 + 有误参考/误版本候选”作为同一个端到端选择事件；unknown 只能是 fallback，不能升级 source-conditioned candidate |

因此下一步不能继续简单增加 crop、频谱支路或 detector。首先要测量**候选集合和树结构是否可信**，再谈局部编辑证据。

## 4. 真实差异与不能声称的内容

### 4.1 可辩护的研究差异

截至本轮检索，没有找到一篇 2024–2026 的一手论文把以下五项同时作为一个可回放统计协议：

1. 登记原件条件的 paired local intervention；
2. 普通传播版本树的相关性和树内最大值；
3. 检索候选集合的漏召回/误召回/恶意植入；
4. reference/version winner selection 的 selection-conditional calibration；
5. unknown generator/no-reference 情况的 fail-closed routing。

这只是“未找到完整组合”的研究审计，不是专利新颖性或全面文献穷尽证明。JOMI、CAP、PEMI 等已经覆盖一般 selection-conditional inference，QuAD 已覆盖质量感知近重复树，RADAR/OpenSDI/DICE 已覆盖局部/开放集 detector。因此 RSCPTN 只能主张一个**来源条件、检索事件级的证据校准协议**，不能主张新的通用 AIGC detector、新的 conformal theory 或新的 propagation tree data structure。

### 4.2 必须撤回的表述

- “p-value 代表 AIGC 概率”或“通过即人类/AI”；
- “检索树完整”或“来源链成立”而实际只有视觉近重复相似度；
- “selection-conditional coverage 已有理论保证”；当前只提出需要在授权数据上验证的 raw rank gate；
- “能解决未知生成器”；unknown 只能得到 `open_set_unknown`，不能回落为人类；
- “鲁棒抵抗攻击”；只能在预注册 decoy injection/poisoning stress 上报告 route/FPR，不能外推到所有攻击。

## 5. RSCPTN-v1 研究协议

### 5.1 研究假设

**H-RSCPTN**：在同一候选检索、同一 reference-selection policy、同一 evidence budget 和同一 split 下，把 ordinary-propagation placebo 通过完整 retrieval→membership→tree→selection pipeline 重放，并与 verified-tree null 同时作为 gate，能够相对 SCPTN/SAEC/SAEA 降低：

- ordinary-propagation false-positive rate；
- wrong-reference / false-match rate；
- retrieval poisoning 造成的 route flip；
- 在固定 coverage 下的一次人工复核分钟和重复复核次数。

局部 AI edit 子集上的 ROI/边界 F 不能恶化超过预注册 margin；未见生成器、image-conditioned editor、neural-rendered 和下一时间窗上 unknown/review 应上升或保持保守，不能靠强制升级掩盖证据不足。

### 5.2 两路 raw null

对 query `q`，先通过冻结的 retrieval policy `π_R` 得到候选集 `C(q)`。membership gate 只允许以下离散层级，不把视觉相似度写成概率：

```text
exact      = 有登记/签名 parent 或可回放 transform 绑定
matched    = 同 asset/pair/frame/schema 且 ordinary transform 可复放
uncertain  = 只有视觉近重复或不完整链信息
outside    = blind decoy、wrong-reference 或明确不属于该 tree
```

在 `exact/matched` 节点上复用 SCPTN 选择器，得到：

```text
T_tree(q) = max_v∈SelectedTree(q) max_r max(0, paired_delta_raw[v,r])
```

`p_tree_raw` 为 `T_tree(q)` 在**独立 verified ordinary-propagation tree profile** 中的 ties-inclusive rank。树 profile 按 `propagation_shape × transform_family × quality_profile × depth_bucket × time_bucket` 分层；同一 tree 禁止拆成独立 calibration rows。

再将同 source 的 ordinary-propagation placebo query 通过同一个 `π_R`、候选 `K`、rank/quality sorting、membership gate、decoy pool、tree selector 和 operator/view budget 重放，得到 end-to-end retrieval statistic `T_retrieval(g)`。`p_retrieval_raw` 为 query 的检索选择统计量在独立 placebo retrieval profile 中的 ties-inclusive rank，profile 额外按以下 selection key 分层：

```text
retrieval_policy_digest
candidate_count_bucket
rank_profile_bucket
membership_tier_histogram
tree_shape_bucket (branch/depth)
quality/transport bucket
open_set/family bucket
action-budget bucket
```

固定双门：

```text
p_joint_raw = max(p_tree_raw, p_retrieval_raw)
```

`p_joint_raw` 只用于保守 raw route；未作多重检验或 coverage theorem 声称。任一路 profile 支持不足、检索污染过高、selection key 未覆盖或 exact/matched 节点不足，均不得用另一路 p 值补成功。

### 5.3 检索污染诊断

每个 retrieval event 保存离散审计字段：

```text
retrieval_candidate_count
exact_count, matched_count, uncertain_count, outside_count
unresolved_parent_count
tree_component_count, branch_count, max_depth
candidate_rank_digest, membership_policy_digest
retrieval_source_bucket, platform_bucket, transform_family
decoy_injection_digest, poisoning_stress_route_flip
```

`uncertain` 节点不能直接进入 candidate statistic；它们必须计入 `uncertain_fraction_raw` 并触发以下之一：

- `retrieval_contaminated_review`：检索选择足够但污染/误召回/decoy stress 使 route 不稳定；
- `open_set_unknown`：无登记原件、family/transform 处于 profile 外或只存在 uncertain near-duplicates；
- `insufficient`：缺独立 profile、支持不足、tree 无法重建或 evidence binding 失败。

RSCPTN 不做“把未知节点加权后继续检验”的伪概率融合。若未来需要 membership score，必须作为独立模型 adapter，在新决策记录和独立校准门批准后才可加入。

### 5.4 固定 raw route

| route | 必要条件 | 语义边界 |
| --- | --- | --- |
| `retrieval_tree_candidate` | exact/matched 支持足够；`p_tree_raw ≤ α` 且 `p_retrieval_raw ≤ α`；D-054/D-058 无冲突；selection key、tree shape、profile digest 和 split 全绑定；decoy stress 不触发 route flip | 只进入人工复核候选；不表示 AIGC、作者、来源真实性或侵权 |
| `retrieval_tree_null_consistent` | query 明确为 ordinary propagation，或双路 raw gate 与 null 一致且没有污染 | 不等于人类创作 |
| `retrieval_contaminated_review` | uncertain/outside 比例过高、误召回/decoy/poisoning 造成 route flip、检索形状超出支持但仍有部分证据 | 进入人工复核；不向 candidate 强制升级 |
| `open_set_unknown` | 无登记原件，或 generator/transform/family 处于 profile 外，或只有视觉近重复而没有 exact/matched link | 交给 D-056/open-set fallback；不等于人类创作 |
| `insufficient` | manifest/权限/哈希/parent/tree/split/profile/operator/view/action budget 任一失败 | 停止推断，保留失败原因和 evidence digest |

禁止输出字段：`aigc_probability`、`confidence`、`human_supported`、`ai_generated_supported`、`author`、`copyright`、`legal_decision`。

`p_*_raw` 是有限样本 rank 摘要，必须带 profile/support/digest；它们不能被序列化为模型概率。`asset_id?` 允许未知原件路线存在，但 `retrieval_tree_candidate` 不得在缺少登记原件绑定时出现。

### 6.1 最小硬门

1. retrieval、membership、tree、selection、evaluation 的策略和 digest 必须冻结；结果不可读绝对路径和作者信息。
2. query tree 与 calibration placebo tree 必须按 asset/group 隔离；同一传播树不得跨 split，也不得拆成独立 calibration rows。
3. observed node 必须有同 frame、同 schema、同 transform 的 ordinary-propagation counterfactual；缺失进入 `insufficient`。
4. selection key 由候选数、rank/quality profile、membership histogram、tree shape、open-set bucket 和动作预算组成；支持不足不能 fallback 到 global threshold。
5. `uncertain`/`outside` 只做污染诊断和拒判触发，不做软权重贡献。
6. ordinary-propagation、blind decoy、wrong-reference 和 poisoning stress 必须使用相同 retrieval policy；否则不能比较 end-to-end 选择偏差。
7. 任何非有限 delta、重复 candidate/node、跨 asset parent、跨 split、digest 冲突、授权过期或输入哈希漂移固定 `insufficient`。

## 8. 最小合成契约和对照矩阵

建议首轮只实现 10–14 个单测和 6–8 个 scalar runner case，证明失败闭合，不引入模型权重：

1. clean local edit：verified tree + retrieval replay 双门通过，得到 `retrieval_tree_candidate`；
2. ordinary propagation：两路 null 一致，固定 `retrieval_tree_null_consistent`；
3. tree-internal max：同一树拆成独立 rows 固定 `insufficient`，证明树级统计单位；
4. false retrieval：`p_tree_raw` 通过但 retrieval placebo profile 不通过，进入 `retrieval_contaminated_review`；
5. missing near-duplicates：候选 count/rank shape 超出 profile，不能 fallback；
6. unknown family/no reference：进入 `open_set_unknown`，不输出 candidate；
7. poisoning injection：添加相似 decoy 后 route flip，进入污染 review；
8. cross-split/tree/digest/authorization/finite-value 失败全部 `insufficient`；
9. exact tie、candidate order 和重复执行 digest 稳定；
10. 序列化不出现 probability/author/copyright/legal 字段。

真实主对照固定为：

```text
query-only
QuAD-like quality aggregation
SCPTN (verified tree only)
D-054 reference specificity
SAEC selection-aware calibration
SAEA vs fixed A9
SCPTN + retrieval integrity gate
RSCPTN dual-null
RSCPTN without retrieval replay / without contamination gate / without tree null
```

所有对照必须共享 query、检索候选、动作预算、split、授权和 detector schema；不能用不同检索结果比较算法。

## 9. 证伪条件、理论风险和停止规则

满足任一条件就撤回“算法创新”，保留为 audit sidecar：

1. 在 matched coverage 和同预算下，RSCPTN 相对 SCPTN/SAEC/SAEA 不稳定降低 ordinary-propagation FPR、false-match、route flip 或人工复核分钟；
2. 主要收益来自提高 `unknown/review` 或降低 coverage，接受样本 selective risk 没有下降；
3. 真实 retrieval event 的 tree/membership 无法可靠重建，`uncertain` 比例导致大多数样本 `insufficient`，或 exact/matched 支持只存在于合成 fixture；
4. 检索污染 placebo 的 null route 未校准，独立 ordinary-propagation profile 上的 candidate rate 超过预注册 raw α 门，或双门与 profile strata 交换性明显失效；
5. unknown generator、image-conditioned editor、下一时间窗或深传播链出现强制 candidate/低 unknown recall；
6. planted decoy 能稳定改变 reference/tree route 而污染诊断未触发；
7. P95、检索存储、重放成本或人工复核成本超过客户门槛；
8. RSCPTN 只是在重新命名 JOMI/CAP/PEMI 的 selection-conditional conformal，无法证明 retrieval-event/profile replay 带来独立工程或统计收益。

当前不宣称有限样本 theorem。即使独立 profile 的 raw rank 在合成数据上看似稳定，也不能外推到真实检索缺失、攻击性污染或跨平台依赖；要获得正式选择条件 coverage，需要另行给出 exchangeability/selection taxonomy 假设和证明。
