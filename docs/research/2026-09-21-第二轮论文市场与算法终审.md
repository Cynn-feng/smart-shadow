# 2026-09-21 第二轮论文、市场与算法终审

更新时间：2026-09-21（Asia/Shanghai）
用途：把 2025–2026 论文前沿、官方市场触发和当前代码缺口收敛为下一项可执行研究切片。本文是研究输入，不替代 `docs/01` 的决策或 `docs/07` 的运行证据。

## 1. 结论

截至本轮核验，没有发现一篇工作同时闭环以下链路：

```text
登记原件 → 普通传播 null → 检索后 winner 选择 → 固定 winner 复核
→ 局部 matched intervention → 开放集拒判 → 来源/生成器分离
→ 反取证压力 → 按查询时点和删除状态可回放
```

论文已经分别覆盖 detector 泛化、局部编辑、生成器归因、开放世界、压缩/再数字化、反取证、水印和可审计解释。因此，Smart Shadow 继续训练单图二分类器的边际价值很低；当前最可辩护的增量是**来源条件证据审计协议**，并把生命周期时序作为一个独立的 fail-closed 维度。

当前排序：

1. **P0：ALG-001 真实检索事件回放 → CFAEA-v1**。先处理选择泄漏、A/B holdout、双注册表和 matched ordinary-null。
2. **P0 工程/研究门：TLEG-v1**。在任何候选路由前校验 as-of 时序、快照新鲜度、事件链、删除墓碑、恢复新版本和授权范围。
3. **P1：AR-SCMI-v1**。只做授权反取证 artifact validator，暂不实现攻击器。
4. **商业 P0：标识/来源 readiness gateway + 私有 DAM/MAM evidence sidecar**。以回放、冲突、删除和人工复核节省计价假设，不按单图 AIGC 分数收费。

## 3. 代码审计发现的正交缺口：生命周期时序

当前 `aigc/retrieval_event_replay.py` 的 `ArchiveEntry` 只有自由字符串 `time_bucket`；`RetrievalArchiveSnapshot` 只有 `archive_version`；`ReplayRequest.evaluation_time` 主要用于授权过期判断，尚未验证 query-as-of、snapshot-created-at、事件单调序列、删除墓碑和恢复版本的先后关系。外部 split 目前统一为 `not_evaluated`，没有 forward-only profile freshness 或 rollback 门。`aigc/compliance.py` 的 observation 也没有 content/version/event digest 的生命周期绑定。

这会产生一个与 CFAEA、AR-SCMI 正交的风险：

- 查询发生后才写入的未来索引/证据可能被回放成当时可见的 candidate；
- 资产删除后，旧 snapshot 仍可能让局部证据继续升级；
- 恢复资产如果没有新的版本事件，旧 digest 可能被误当成当前有效版本；
- stale profile 或跨租户授权过期可能被当成普通 `review`，而不是终止路由。

### TLEG-v1（Temporal-Lifecycle Evidence Gate）最窄主张

> 对任一 AIGC/来源证据路由，在候选前强制验证 query-as-of、snapshot freshness、单调事件链、授权/留存、删除墓碑与恢复新版本；这是否能把 future/stale/tombstoned evidence 的错误升级降为零，同时不引入不可接受的 coverage、P95 和人工成本损失？

TLEG 不检测 AIGC，也不输出概率；它是所有 PC-SCFT、RSCPTN、ALG-001、CFAEA 和后续 AR-SCMI 的时序前置门。

建议输入：`event_id`、`asset_id`、`version_id`、`parent_version_id`、`query_as_of`、`snapshot_created_at`、`index_epoch`、`effective_from`、`effective_to`、`monotonic_seq`、`prev_event_digest`、`deletion_tombstone_digest`、`retention_policy_digest`、`authorization_digest`、`access_digest`、`split`、`time_window`、上游 selection/replay/evidence digest，以及 `active|deleted|restored|expired` 状态。

建议 raw route：`lifecycle_consistent`、`future_event_leak`、`stale_snapshot_review`、`tombstoned_insufficient`、`deletion_replay_mismatch`、`profile_stale`、`insufficient`、`not_evaluated`。其中 `lifecycle_consistent` 只允许下游继续，不等于 candidate；普通传播、unknown generator 或 source conflict 不能通过 TLEG 被修复。

最小可证伪门：

1. future snapshot、序列重排/重复/断链、删除后仍 candidate、恢复但未形成新版本、授权过期和跨 tenant 必须 100% fail closed；
2. 同一输入顺序回放 digest 稳定，任何 event/manifest/snapshot/digest 篡改均改变结果或拒判；
3. 在同一 manifest 上比较 ALG-001/CFAEA + TLEG、去 TLEG、latest-snapshot 和随机 split，报告 stale/future candidate upgrade（目标 0）、删除/恢复回放成功率、route flip、coverage、unknown/review、P95、存储和人工分钟；
4. 真实数据至少包含一个过去窗口、一个未来窗口、删除墓碑和恢复演练；没有这些只能做 fixture contract，不能称 temporal generalization 或 AIGC 效果。

## 4. 市场与商业价值收敛

### P0-A：中国法域标识/来源 readiness gateway

中国《人工智能生成合成内容标识办法》要求生成服务保留显式/隐式标识，传播服务核验元数据、用户声明和生成痕迹，导出/复制应保留显式标识；欧盟委员会已发布 Article 50 指南并自 2026-08-02 适用透明度义务。C2PA 2.4 又加入 repository receipt 和 AI disclosure，但明确 crJSON 是派生视图，不能独立验证。

最小产品是单法域、单图片内容类型的只读 parser/rule/report/replay sidecar：保存原始字节、parser/spec/trust/version、C2PA/GB/IPTC/EXIF/XMP/platform ID、缺失/变更/冲突、人工处置和回执。目标买方是 AI 内容平台、媒体/品牌内容中台、监管/合规服务商；替代是平台内置 C2PA/检测、Adobe、TikTok、YouTube 和人工脚本。

公开采购只能作为需求触发：中信院公开招标采购图像 AIGC 鉴伪服务器，江苏通信管理局公开图片违法违规检测服务采购意向约 25 万元；这些用途和预算不能外推为 Smart Shadow 客户或报价。四周 shadow 指标：解析覆盖、显式/隐式标识识别、回放成功率、冲突/unknown、静默假成功（必须为 0）、P50/P95、每千件成本和人工分钟。

### P0-B：私有 DAM/MAM provenance/version/evidence sidecar

这是 Smart Shadow 更有差异化的方向。C2PA、Adobe、TikTok、YouTube 已覆盖基础凭证/标签，Smart Shadow 应把增量放在跨来源冲突、父子版本、删除/恢复、权限、检索选择和人工 evidence package。最小 shadow 是 500 个授权原件与约 1,000–2,000 个传播/编辑版本，四周只读，记录绑定正确率、字段完整率、冲突率、删除/恢复回放、evidence package 一次通过率、P50/P95、每千件成本和人工复核分钟。

武汉市监关于可信数据空间和 AI 知识库的询价包含结构化/非结构化上链、元数据规范、哈希、跨源关联标识和执法证据存证，说明付费形态更接近“规范+咨询+实施+回放”而不是一个 detector 分数。停止条件：无法做租户权限/删除回放、失败仍返回成功、四周无重复任务、报告不被流程采用或净人工价值为负。

### P1-C：平台 Trust & Safety / 版权争议复核 sidecar

平台已有内建标签和检测，直接替换风险高。更现实的切口是区域平台、企业内容中台或跨平台争议复核：保存原件/版本/传播、标识冲突、检索候选、wrong-reference/decoy 和人工意见，绝不自动下架、索赔或判定侵权。需要平台或权利方提供匿名人工裁决样本，不能用公开政策替代试点。

### P1-D：训练许可、排除与撤回台账

Adobe 已提供“不用于训练/生成使用”偏好，但只由部分支持方执行；美国版权局报告也指出 opt-out 的执行和识别困难。可卖的是 manifest diff、撤回/删除回放和下游回执，不卖“证明某图被训练过”。没有书面权利规则、删除责任人和两次以上 manifest 版本变化时停止。

### 商业禁区

- 不卖 C2PA viewer、单图 AIGC 百分比或替代平台内置检测；
- 不把政府采购预算、企业年报、论文 AUC 当作 Smart Shadow 客户、价格、收入、ROI 或部署证据；
- 不把相似检索写成训练 membership，不把 `not_detected` 写成人类创作，不把 `null_consistent` 写成没有 AI；
- 不在阶段 1–5、权限、删除、恢复和人工基线未通过前读取客户数据或接发布线上接口。
