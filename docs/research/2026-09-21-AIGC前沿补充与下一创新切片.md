# 2026-09-21 AIGC 前沿补充与下一创新切片

更新时间：2026-09-21（Asia/Shanghai）
证据范围：2025–2026 年正式会议论文、会议官方页面、作者 arXiv 原文和官方项目页。
用途：补充已有 AIGC 调研，审计局部编辑、普通传播、未知生成器和选择后取证的先例，并提出可回滚、可证伪的下一代码切片。
状态：外部研究输入和实验设计建议；不代表 Smart Shadow 已有真实图片效果、AIGC 概率、部署能力或法律结论。

## 1. 结论先行

“解决 AIGC”不能再定义为训练一个更大的二分类器。2025–2026 年公开工作已经分别覆盖全图/局部 AI 编辑、像素定位、grounded explanation、跨范式未知生成器、JPEG/resize/社交传播、近重复聚合、测试时适配和预算化证据采集。

因此 Smart Shadow 不能把 CLIP、频谱、熵、crop、热力图、单图概率、近重复质量加权或开放集 detector 单项写成新算法。更值得继续验证的问题是：

> 当同一登记原件的 query 已在网络上形成相关的传播版本树时，怎样在不重复计数相关版本的前提下，用同坐标帧的 observed–ordinary-propagation counterfactual 局部差异，控制参考选择偏差和普通传播误报，并在证据不足时拒判？

建议的下一切片是 **SCPTN-v1（Source-Conditioned Propagation-Tree Null）**：把版本树作为统计单位，在独立、树形/传播族/质量分层匹配的 ordinary-propagation tree null 上，校准树内版本选择后的最大局部效应。它不是新的 detector，也不声称因果识别；只有在相同覆盖率、相同证据预算下减少普通传播 FPR、参考误配和人工复核分钟，才有资格讨论研究增量。

## 4. 尚未覆盖的真实缺口

### 4.1 统计单位未对齐

已有 near-duplicate quality fusion、paired propagation stability、paired-delta calibration、D-054、D-060 和 D-061，但尚缺树级契约：

1. 同一 query 的传播版本不是独立样本；逐版本平均/检验会重复计数相关证据。
2. 选质量最高或局部效应最大的版本后再评估会产生 tree-internal winner's curse。
3. 现有 paired-delta profile 主要按 transform family × quality bucket，未要求 calibration null 与 query 具有相同树形、分支数、传播深度和选择策略。
4. 普通裁剪/压缩可能产生局部边界差异，只有同 source、同 canonical frame、同 transform family 的 no-edit counterfactual 才是可比 null。

必须预注册树内选择策略，并在树级 ordinary-propagation null 上校准同一个选择统计量，而不是再加一个阈值。

### 4.2 未知生成器 hardest split 不完整

至少联合切分：

    generator_family × generation_paradigm(text-only / image-conditioned / layered / neural-rendered)
    × prompt/style/domain × propagation_depth/platform × time_bucket

image-conditioned 编辑和传播后的局部编辑要与无原件 detector 和登记原件条件分别报告，否则所谓未知泛化可能只是内容或压缩捷径。

### 4.3 主动取证缺少策略级对照

SAEA 已记录动作、成本、输入/输出 digest 和失败原因，但尚未证明在相同 max_actions、cost_units、evidence split 下，按失败原因选 probe 比固定顺序 A9 更少误升级或人工复核。BCEA 提醒：采集会改变选择过程，必须在采集后重新校准，不能把多看几次的最高分直接当证据。

## 5. 建议下一代码切片：SCPTN-v1

### 5.1 研究假设

H-SCPTN：对同一登记资产的传播版本树，使用预注册树内版本选择策略，并在独立、树形/传播族/质量匹配的 ordinary-propagation null tree 上校准相同的树级最大局部效应。相对逐版本评估或简单质量加权，目标是在固定 coverage 和固定证据预算下：

- 降低 ordinary-propagation FPR；
- 降低错误 reference/version false-match；
- 减少 route flip 和重复人工复核；
- 在局部 AI 编辑子集维持 ROI/边界质量；
- 对未见 image-conditioned generator、下一时间窗和深传播链保持保守 unknown/review。

若它只提高拒判、只在 IID/已知生成器改善，或以 coverage 换取表面收益，则保留为 evidence-audit sidecar。

### 5.2 与已有模块的关系

    registered reference
            │
            ├── query/version propagation tree
            │      ├── observed local deltas
            │      └── same-transform ordinary-propagation counterfactuals
            │
            ├── D-054 blind reference specificity
            ├── D-058 view/operator invariant effect
            ├── D-060 selection-aware calibration
            └── D-061 budgeted acquisition trace
                     │
                     ▼
           SCPTN tree-level null calibration
                     │
          group_candidate / group_null_consistent /
          group_inconsistent / insufficient

SCPTN 不训练 detector、不替换 D-054/D-058/SAEC/SAEA、不改写 aigc_result_v1，只接受已绑定 regional raw evidence 和传播图审计信息。

### 5.3 最小输入契约

每个 query tree：

    tree_id, asset_id, pair_id, manifest_digest, canonical_frame_digest
    candidate_reference_digest, selection_policy_digest
    node_id, parent_node_id, branch_id, depth, propagation_chain
    role = observed | ordinary_propagation_counterfactual
    transform_family, quality_score, quality_bucket
    region_id, region_bbox, observed_score_raw, counterfactual_score_raw
    paired_delta_raw, paired_delta_p_value (if available)
    detector_version, score_schema, operator_set_digest, view_set_digest
    selection_split_digest, calibration_tree_split_digest, evaluation_tree_split_digest

硬门：

1. 一个 tree 只能属于一个 asset/pair/split；不能跨 selection、calibration、evaluation。
2. 纳入选择统计量的 observed node 必须有同变换、同坐标帧、同 region schema 的 ordinary-propagation counterfactual。
3. parent/branch/depth、传播参数、质量桶和 input digest 必须可回放；未知 parent、重复 node、跨资产合并和非有限 delta fail closed。
4. calibration tree 不能由 query 的传播版本或 decoy 复用；null profile 以 tree 为单位，禁止把同一树拆成独立样本。
5. 只保存 digest/ID/数值摘要，不写绝对路径、作者或法律字段。

### 5.4 预注册统计量

先固定一个可审计 rank-based 统计量：

1. 对 accepted node，令 T_v = max_r max(0, paired_delta_raw[v,r])。
2. 预注册 tree policy：每个 branch_id、depth_bucket、quality_bucket 最多选一个 node；先按质量降序，再按 node_id 字典序打破平局。策略不能看 evaluation 标签。
3. 对整棵 calibration null tree 用同一 policy，计算

    T_tree = max(T_v for v in selected nodes)
    p_tree = (1 + count(null_tree_T >= T_tree)) / (1 + number_of_calibration_trees)

4. null tree 按 propagation_shape × transform_family × quality_profile × time_bucket 分层；exact 支持不足只能显式 family/global fallback，并保存 level、support、profile digest。
5. p_tree 只检验树级局部效应是否超出 ordinary-propagation tree null，不是 AIGC probability、作者概率或来源真实性概率。

先用 max 是为了让树内选择和校准同构；冻结 manifest 后再比较 quality-conditional likelihood、trimmed aggregate 或 branch-level closed testing，不能看结果后切换统计量。

### 5.5 Raw route

- group_candidate：p_tree ≤ alpha，D-054/D-058 无冲突，source/canonical/quality/transform binding 完整；只进入人工复核候选。
- group_null_consistent：树级统计量与 ordinary tree null 一致，或 query 明确是普通传播；不等于人类创作。
- group_inconsistent：跨 branch/view/operator 冲突、tree route flip、counterfactual 激活或 reference 不稳定；进入 review/unknown。
- insufficient：树形、配对、split、支持数、digest、质量、schema 或权限任一失败。

结果禁止 probability、confidence、human_supported、ai_generated_supported、author、copyright 和法律裁决字段。

### 5.6 建议的代码和测试切片（本轮不直接实现）

    aigc/source_conditioned_tree_null.py
    tests/test_source_conditioned_tree_null.py
    eval/source_conditioned_tree_null_eval.py

最小测试矩阵：

1. 单树、双 branch、多 depth、多 quality bucket 的确定性统计量；
2. 把同树节点拆成独立样本时固定拒绝，证明 tree-level unit 生效；
3. query/calibration split 相等、树形 digest 相等或 tree 泄漏时 insufficient；
4. 缺 counterfactual、坐标帧/transform/schema 不一致时 fail closed；
5. 质量/最大 delta 选择可回放，ties 和 node 顺序稳定；
6. exact/family/global fallback 的 level、support、profile digest 完整；
7. blind decoy/wrong reference 只能得到 group_inconsistent/insufficient；
8. D-058 不稳定或 D-061 预算耗尽时不能升级；
9. 非有限值、重复 node、跨资产 parent、跨 split、未知操作均拒判；
10. 序列化禁止概率、作者、版权和法律字段；
11. 重复执行 result/evidence/dataset digest 一致；
12. runner 覆盖 local edit、ordinary propagation、wrong reference、low quality、unknown generator、missing evidence。

runner 只输出 raw route、树级统计量、null support、digest、route counts 和拒判原因，不输出 AUROC、AIGC 概率或产品状态。

### 5.7 真实验证与证伪门

对照固定为：

    query-only
    near_duplicate quality fusion
    propagation_stability
    D-054 reference specificity
    D-054 + D-058
    D-060 SAEC
    D-061 SAEA + fixed A9
    SCPTN-v1
    SCPTN without tree null / without counterfactual / without selection gate

同一授权 manifest、检索候选和动作预算下报告 ordinary-propagation FPR、reference false-match、ROI AP/F1、boundary-F、risk@coverage、coverage、unknown/review、route flip、text-only/image-conditioned/layered/neural-rendered 分层、known/unseen generator、source domain、prompt/style、传播平台/深度、下一时间窗、P50/P95、每千张成本、证据包回放成功率和人工复核分钟。

必须通过 G0–G6：授权/删除、同源普通传播 null、真实编辑 mask、开放集/误配 hard negative、独立 calibration、同 manifest 消融、回放/人工/部署门。任何一门未通过都保持 raw evidence、review 或 insufficient。

证伪条件：

1. 相对 D-060/D-061 没有稳定降低 ordinary-propagation FPR、false-match 或人工分钟；
2. 只在 IID/已知生成器改善，传播后或 image-conditioned 未知编辑崩溃；
3. 主要收益来自更高 unknown/review，接受样本 selective risk 不下降；
4. tree 形状/版本关联无法可靠获得，或近重复误配率过高；
5. P95、存储和人工复核成本超过客户门槛。

满足任一条件即撤回“算法创新”，保留 provenance/evidence audit sidecar。
