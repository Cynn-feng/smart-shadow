# 2026-09-21 论文前沿深度审计与可证伪白区

更新时间：2026-09-21（Asia/Shanghai）
任务：SS-030（论文前沿审计）
证据范围：2025–2026 正式会议论文、会议官方页面、作者/官方代码仓库、C2PA 官方规范和欧盟委员会/欧盟法规页面。预印本单独标为 `C`，不得当作正式 benchmark 结果。
用途：研究输入、先例覆盖审计和实验设计；不代表 Smart Shadow 已有真实图片效果、客户、部署、合规认证或法律结论。

## 1. 结论

这一轮没有发现单篇工作同时提供以下闭环：登记原件、同资产普通传播 null、检索后候选选择、局部编辑成对干预、反取证压力、来源与生成器信号分离，以及证据不足时的可回放拒判。单项能力已经被覆盖得很充分：

- **检测/定位**：OpenSDI、X-Edit、RADAR、Detective SAM、UniAIDet、SAFE 和 ForensicHub 已覆盖整图、局部编辑、像素定位、操作链、跨编辑器或统一 benchmark。
- **时间和真实世界泛化**：AI-GenBench 把生成器按历史顺序加入，RRDataset 测社交平台多轮传播与再数字化，2026 年开放模型零样本 benchmark 测出不同 detector 和商业模型间的大幅漂移。
- **表征与开放集**：RGB/NPR 跨模态表征、single-class/real-only、LIDA 检索式生成器归因、IAR provenance 都提供了无原件或生成器信号的先例。
- **主动 provenance 与反取证**：StableGuard、用户/模型水印和 C2PA 处理主动标记；`Untraceable DeepFakes`、`Erasing the Invisible`、`Authenticated Contradictions` 说明水印和生成指纹都会被移除、伪造或与凭证语义冲突。

因此 Smart Shadow 最窄、可实现、可证伪的研究方向应是：

> **Attack-robust source-conditioned matched intervention（AR-SCMI）**：在同一登记原件和 canonical frame 下，把 observed query 与同传播族 ordinary-propagation null 施加同一份已记录的反取证/传播压力，再比较局部干预效应的差值是否仍超过 null envelope；攻击导致的信号冲突、不稳定或来源/生成器不一致统一进入 `review`/`unknown`，不回退为 AIGC 或人类结论。

这不是新的 detector、频域特征、水印、攻击算法或共形理论。可辩护的白区假设只在组合协议：**相同压力下的 source/query/null matched intervention 是否能减少反取证造成的错误升级和普通传播误报**。文献审计没有证明该组合具有专利新颖性；只有真实授权数据和外部攻击切分通过 G0–G6，才可讨论研究增量。

## 3. 基准与评测先例：已经覆盖什么

### 3.1 UniAIDet（2025 预印本，C）

来源：[UniAIDet: A Unified and Universal Benchmark for AI-Generated Image Content Detection and Localization](https://arxiv.org/abs/2510.23023)，另见[公开评审页面](https://openreview.net/pdf?id=J1H2QAqnd2)。

- **方法/数据**：把照片和艺术图像放进同一评测，覆盖 text-to-image、image-to-image、inpainting、image editing 和 deepfake；同时考察生成器泛化，以及 image-level detection 和 localization 的关系。
- **覆盖边界**：它把内容类型、生成方式和定位任务放在统一 benchmark 中，但摘要没有给出登记原件、传播版本树、普通传播 counterfactual、候选参考选择或删除/权限审计。
- **Smart Shadow 对照**：作为外部 task matrix，增加摄影/艺术/扫描/数字绘画分层；同一冻结 manifest 上比较 query-only、reference/query、ordinary-null matched intervention 和无原件 fallback，并报告 unknown/review 与 risk@coverage，而不是只报二分类 AUC。
- **不可外推**：这是预印本；其数据和分数不能支撑项目 detector 的真实授权效果，也不能把 localization 当成 AIGC 或来源证明。

### 3.2 AI-GenBench（IJCNN 2025，A；官方代码 B）

来源：[官方论文入口和代码](https://github.com/MI-BioLab/AI-GenBench)，[论文 DOI](https://doi.org/10.1109/IJCNN64981.2025.11228377)。

- **方法/数据**：以生成器历史顺序构造 temporal evaluation；训练/评估框架把 2017–2024 的多类生成器按时间逐步加入，用过去模型训练并测试后续模型，避免任意随机 split 把未来生成器泄漏进训练。代码以 BSD-3-Clause 发布，图片仍需按各来源仓库的许可核查。
- **覆盖边界**：它直接暴露“闭集随机切分看似很高、时间下一代失效”的问题，但不表示某个 query 来自某个登记原件，也没有普通传播 null、错误 reference 或局部干预因果。
- **Smart Shadow 对照**：将 `generator_family` 与 `time_window` 作为校准/评估分层，固定 `selection/calibration/evaluation` split；比较旧 profile 回放、增量 profile 和拒判/回滚，报告 next-window risk@coverage、unknown recall、旧类遗忘和人工复核分钟。
- **不可外推**：公开 benchmark 的时间轴不等于项目客户时间轴；不允许把外部 temporal score 写成 Smart Shadow 的持续学习能力。

### 3.3 OpenSDI（CVPR 2025，A）

来源：[CVPR 官方论文页](https://openaccess.thecvf.com/content/CVPR2025/html/Wang_OpenSDI_Spotting_Diffusion-Generated_Images_in_the_Open_World_CVPR_2025_paper.html)。

- **方法/数据**：覆盖整图 diffusion synthesis、局部 inpainting、对象插入、背景替换和未见扩散模型；论文描述的 OpenSDID 包含约 300,000 张真实/生成图，并以 SAM/Florence 生成区域 mask。
- **覆盖边界**：局部/全局检测和 open-world 泛化已有强先例，但其 mask 是生成管线标签，不是登记原件版本责任；不校准同资产 ordinary-propagation、wrong-reference 或检索 winner's curse。
- **Smart Shadow 对照**：把 OpenSDI 风格 detector/数据作为无原件 baseline；必须加入 source/query/null/decoy 四元组、质量/传播分层和 `unknown`，并报告 ordinary-propagation FPR、ROI boundary-F 和 route flip。
- **不可外推**：OpenSDI 的 open-world 结果不能替代来源 evidence，也不能说明 query 的作者、版权或侵权责任。

### 3.4 RRDataset（ICCV 2025，A）

来源：[ICCV 官方论文页](https://openaccess.thecvf.com/content/ICCV2025/html/Li_Bridging_the_Gap_Between_Ideal_and_Real-world_Evaluation_Benchmarking_AI-Generated_ICCV_2025_paper.html)，[公开数据入口](https://zenodo.org/records/14963880)。

- **方法/数据**：从战争与冲突、灾害、政治社会、医疗公共卫生、文化宗教、劳动生产和日常生活七类场景取材；测试社交平台多次分享造成的传播损伤，以及四种再数字化过程；比较 17 个 detector、10 个 VLM，并含 192 人的人类研究。
- **覆盖边界**：它说明真实场景、平台传播和人类适应性会改变排名；但没有登记原件/版本图、编辑 mask 与 source-conditioned null，不能衡量来源条件局部证据。
- **Smart Shadow 对照**：把平台和再数字化写为 `transform_family`，与授权原件的 ordinary-propagation 版本配对；报告 transform-level FPR、质量桶 ECE/Brier、unknown/review 和 P95，不只报告平均 AUC。
- **不可外推**：外部人类研究不能替代项目指定 reviewer 的复核基线；RRDataset 的许可、场景和传播链不能直接变成商用训练集。

### 3.5 X-Edit（CVPR Workshops 2025，B/A）

来源：[CVPRW 官方论文页](https://openaccess.thecvf.com/content/CVPR2025W/XAI4CV/html/Bazyleva_X-Edit_Detecting_and_Localizing_Edits_in_Images_Altered_by_Text-Guided_CVPRW_2025_paper.html)。

- **方法/数据**：对图像做预训练 diffusion inversion，把 inverted features 输入带 channel/spatial attention 的 segmentation network，并用 segmentation + relevance loss 定位 text-guided diffusion 局部编辑；同时发布成对原图/编辑图数据。
- **覆盖边界**：它覆盖 paired original/edit 与局部 mask，说明 diffusion inversion/分割已经是局部取证先例；不处理普通传播伪影、检索候选误配、开放集 provenance 冲突或证据拒判。
- **Smart Shadow 对照**：将 X-Edit-like localizer 作为 `source-residual`/ROI adapter；固定 external/edit mask，不让 A/B detector 重新选择显眼 patch；加入同传播 null、blind decoy、错误 reference、截图/再编码和多算子稳定性。
- **不可外推**：局部 mask 指标不能说明编辑由 AI 完成，也不能说明某个登记资产或作者。

### 3.6 2026 开放模型零样本 benchmark（预印本，C）

来源：[How well are open sourced AI-generated image detection models out-of-the-box](https://arxiv.org/abs/2602.07814)。

- **方法/数据**：零样本评估 16 种方法、23 个已发布 detector 变体、12 个数据集、约 260 万张图和 291 个生成器；摘要报告不同数据集排名不稳定、同架构因训练数据对齐出现 20–60% 方差，以及 Flux/Firefly/Midjourney 等商业生成器使多数 detector 平均准确率明显下降。
- **覆盖边界**：它直击“论文 fine-tune 分数不能代表 out-of-box 部署”的风险，但属于预印本，且是 image-only、固定公开模型和公开数据；没有 source registry、ordinary null、编辑 mask 或客户人工工作流。
- **Smart Shadow 对照**：在阶段 7 只把它作为 adapter selection 和 deployment-risk 依据；冻结 detector/schema/profile，报告每个流的支持范围、漂移、P95、未知率和回滚，而不是追逐单一冠军 detector。
- **不可外推**：预印本的排序、商业模型分数、数据量和阈值不能转写成项目准确率或市场 SLA。

### 3.7 ForensicHub（NeurIPS 2025，A）

来源：[NeurIPS 官方页面](https://proceedings.neurips.cc/paper_files/paper/2025/hash/5d8a47fc1cb0a143f149ee07321621c9-Abstract-Datasets_and_Benchmarks_Track.html)，[官方代码](https://github.com/scu-zjz/ForensicHub)。

- **方法/数据**：以配置驱动 adapter 统一 deepfake、IMDL、AIGC 和文档篡改，包含 23 个数据集、42 个 baseline、6 个 backbone、11 个 GPU 指标和跨域融合评测。
- **覆盖边界**：评测模块化、可复现和跨域对照已有先例；这意味着 Smart Shadow 的 manifest、detector、transform、calibration 和 evaluator 组合方式属于工程可比性要求，不是算法独创。
- **Smart Shadow 对照**：把自己的 raw sidecar 适配为可独立回放的 evaluator；同时保留权限、删除、来源和 null gate，这些不由统一 benchmark 自动提供。
- **不可外推**：模块化 benchmark 不证明真实授权、链回执、客户恢复或生产部署。

## 4. 方法与威胁先例：需要作为 baseline 或红队

### 4.1 RADAR（NeurIPS 2025，A）

来源：[NeurIPS 官方页面](https://proceedings.neurips.cc/paper_files/paper/2025/hash/36721d1209a059dcb7a090dd543f34c4-Abstract-Conference.html)，[官方项目页](https://alex-costanzino.github.io/radar/)。

RADAR 将 foundation-model 的多模态特征和 patch-level contrastive loss 用于 diffusion inpainting 区域检测，并用包含 28 个 diffusion model 的 BBC-PAIR 测试 seen/unseen 编辑器。它已经覆盖局部检测、定位和跨模型泛化，因此 Smart Shadow 不应再做“另一个 patch detector”。必须把它当作 localizer baseline，测试同一 source/query/null/decoy 在反取证压力下的误报和 route flip。

### 4.2 Detective SAM（ICLR 2026，A）

来源：[ICLR 官方页面](https://proceedings.iclr.cc/paper_files/paper/2026/hash/262dd62fd1bbb30d6a6b4d578f5e65ff-Abstract-Conference.html)，[官方代码](https://github.com/Gertlek/DetectiveSAM)。

Detective SAM 将 SAM2、扰动驱动取证线索和 mask adapter 组合，并用 AutoEditForge 持续生成新编辑样本；论文摘要报告新编辑会令现有定位器崩溃，500 个 AutoEditForge 样本可恢复一部分定位性能。其增量是 continual localizer/数据引擎，不是来源条件 null。Smart Shadow 应记录 `generator_family`、`edit_operator`、`support_manifest_digest` 和旧 profile 回归，不能因少量新编辑样本恢复 IoU 就声称开放集来源解决。

### 4.3 RGB/NPR 跨模态表征（CVPR 2026，A）

来源：[CVPR 官方页面](https://openaccess.thecvf.com/content/CVPR2026/html/Gong_Cross-modal_Representation_Learning_for_Diffusion-generated_Image_Detection_CVPR_2026_paper.html)。

该工作把 RGB 与 neighboring-pixel relationship（NPR）放进 cross-modal contrastive learning 和 mutual distillation，在 GenImage、DRCT-2M、Co-Spy-Bench 上做 diffusion detection。它说明低层关系流可以作为 detector adapter，但仍没有登记原件、传播 null、局部 intervention 或错误 reference。项目必须对 RGB/NPR/SRM/DCT/source-residual 做独立流消融，禁止把“多流融合”单独称创新。

### 4.4 Data Provenance for Image Auto-Regressive Generation（ICLR 2026，A）

来源：[ICLR 官方页面](https://proceedings.iclr.cc/paper_files/paper/2026/hash/5a1667459d0cdeb2fe6b2f0dffc5cb9d-Abstract-Conference.html)。

该工作针对 image autoregressive（IAR）模型，从生成过程残留模式做 post-hoc provenance tracing，不需要修改生成器或嵌入 watermark。它扩大了 `generator_registry` 的覆盖范围，提醒项目不能只测 diffusion；但其信号是模型来源候选，不是资产 registry 的登记来源，不等于作者/版权事实。实验应把 IAR 作为 unseen generator family，并把 generator signal 与 source-specific effect 分开存储。

### 4.5 StableGuard（NeurIPS 2025，A）

来源：[NeurIPS 官方页面](https://proceedings.neurips.cc/paper_files/paper/2025/hash/15972a9575e0f03bf82f00aebeb40774-Abstract-Conference.html)。

StableGuard 在 latent diffusion 生成阶段联合嵌入 binary watermark，并用 watermark-free/watermarked pair、随机 mask 和 MoE forensic network 做 tamper localization。它属于**生成器可控、主动 provenance**路径，不能解决已经上传、无密钥、被再传播的图片。Smart Shadow 只能把它作为 provider-enabled watermark adapter；检测结果与视觉/null evidence 冲突时必须 `review`，不能回写成“真实”或“版权所有”。

### 4.6 Untraceable DeepFakes via Traceable Fingerprint Elimination（ICLR 2026，A）

来源：[ICLR 官方页面](https://proceedings.iclr.cc/paper_files/paper/2026/hash/8e8399e5e7aed601c9f135f40be26564-Abstract-Conference.html)。

该工作提出乘法式 fingerprint-elimination attack，以 real data 训练且不依赖具体 attribution model；摘要报告对 6 个 attribution model、12 个 generator 平均 97.08% attack success rate，带防御时仍超过 72.39%。它证明“生成器指纹/水印被移除”必须是红队压力，而不是默认稳定 evidence。项目不能实现或发布攻击器作为产品能力；只在获授权、脱敏的外部攻击输出上评估 matched query/null，并保留 attack digest、许可和删除记录。

### 4.7 Authenticated Contradictions（CVPRW 2026，B/A）

来源：[官方论文 PDF](https://openaccess.thecvf.com/content/CVPR2026W/APAI/papers/Nemecek_Authenticated_Contradictions_from_Desynchronized_Provenance_and_Watermarking_CVPRW_2026_paper.pdf)，[官方代码](https://github.com/ANCP2021/integrit-y-clash)。

该工作构造 C2PA manifest 声称人类编辑、像素 watermark 指向 AI 的跨层冲突，并提出联合审计；摘要称其在 3,500 张测试图、四类冲突和三种扰动上得到其 benchmark 的 100% 分类。它覆盖的是 provenance 与 watermark 语义同步，Smart Shadow 应吸收其 `conflict matrix`，但不能把外部数字当项目结果，也不能把冲突自动解释成侵权或作者事实。

### 4.8 质量感知校准、压缩相位与真实传播

来源：[DACOM/ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/482847908fd916b5b6b9e82525c773ad-Abstract-Conference.html)、[Phase Spectrum Robustness/CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Li_Detecting_Compressed_AI-Generated_Images_via_Phase_Spectrum_Robustness_CVPR2026_paper.html)、[Quality-Aware Calibration/CVPRW 2026](https://openaccess.thecvf.com/content/CVPR2026W/APAI/html/Guillaro_Quality-Aware_Calibration_for_AI-Generated_Image_Detection_in_the_Wild_CVPRW_2026_paper.html)。

这些工作分别覆盖失真可检测性、压缩后频谱鲁棒和近重复质量条件校准。它们要求 Smart Shadow 保留质量/传播分层、拒判和 profile digest；但质量分桶、phase 特征或近重复聚合不能替代 source-conditioned matched null，也不能变成 AIGC 概率。

## 5. 标准与监管边界：C2PA 2.4 与 EU AI Act Article 50

### 5.1 C2PA 2.4 的技术事实

来源：[C2PA Technical Specification 2.4](https://spec.c2pa.org/specifications/specifications/2.4/specs/C2PA_Specification.html) 和[Content Credentials](https://spec.c2pa.org/specifications/specifications/2.4/specs/ContentCredentials.html)。

- 2.4 新增 `c2pa.ai-disclosure`，用于 machine-readable AI transparency；新增 `c2pa.repository-receipt`，用于证明 manifest 已被仓库摄取；同时新增 crJSON 派生视图。
- `actions`、`ingredients`、`digitalSourceType`、`humanOversightLevel` 等字段用于记录创作/编辑过程和声明，仍受签名、信任列表、解析器和凭证保留约束。
- 官方规范明确 crJSON 是派生视图，不能独立验证或作为输入格式；因此 Smart Shadow 不能把导出的 JSON 文本当作签名真实性。

**产品映射**：优先做 `metadata_mutation_guard + provenance_conflict_replay` sidecar：保存原始 manifest/claim digest、`specVersion`、解析器/Trust List 版本、`ai-disclosure`/`actions`/`ingredients` 摘要、repository receipt、验证错误、删除/恢复和导出回执。输出限定为 `pass`、`gap`、`conflict`、`insufficient`；不输出“内容真实”“版权所有”或“符合 AI Act”。

### 5.2 EU AI Act Article 50 的技术/产品边界

来源：[欧盟委员会 Article 50 透明度指南](https://digital-strategy.ec.europa.eu/en/policies/guidelines-ai-transparency-obligations)、[Article 50 FAQ](https://digital-strategy.ec.europa.eu/en/faqs/transparency-obligations-under-article-50-ai-act)、[最终 Code of Practice](https://digital-strategy.ec.europa.eu/en/news/commission-publishes-code-practice-marking-and-labelling-ai-generated-content) 和[法规原文](https://eur-lex.europa.eu/legal-content/EN/TXT/PDF/?from=EN&uri=CELEX:32024R1689)。

- 欧盟委员会页面说明 Article 50 透明度义务自 **2026-08-02** 起适用；AI providers 需设计 machine-readable marks 以支持 AI 生成/操纵内容的检测，deployers 在适用情形下需告知交互、标注 deepfake，以及未经人工审校的公共利益 AI 文本。

**Smart Shadow 的产品白区**：做私有 DAM/MAM 的凭证解析、版本/来源/水印冲突回放、人工复核工作台和审计导出；把 visual detector 作为可替换、可拒判的 evidence adapter。不要售卖“AI 真伪裁决”“自动版权确权”或“单靠 detector 的 AI Act 合规”。

## 7. 建议的唯一窄算法切片：AR-SCMI-v1

### 7.1 研究问题

给定登记原件 `r`、观察 query `q`、同资产 ordinary-propagation null `n` 和固定区域/算子，普通传播或反取证会让局部 detector 产生多大漂移？如果对 `q` 和 `n` 施加同一已授权压力，source-conditioned contrast 是否仍可区分？

这不是“训练一个更强 detector”，而是验证**攻击造成的共同模式漂移是否能被 matched null 抵消**。

### 7.2 最小输入

```text
reference / observed / ordinary_propagation_null
canonical_frame_digest / asset_id / pair_id
proposal_mask_digest / operator_set_digest
attack_spec_digest / transform_family / quality_bucket
detector_version / score_schema / calibration_profile_digest
authorization_id / authorization_scope / deletion_expiry
```

攻击样本必须来自授权 red-team 生成包或外部官方 benchmark，项目不在本切片中实现攻击器。每个 `attack_spec` 同时作用于 `q` 与 `n`，并保存输入/输出 digest、工具版本、参数、许可和失败原因。

### 7.3 统计量与路由

对每个攻击压力 `a`，先计算现有 PC-SCFT 的 source-conditioned local effect：

```text
C_a = intervention_effect(observed_a, reference_a, M, op)
      - intervention_effect(null_a, reference_a, M, op)
```

在独立 ordinary-propagation calibration groups 上估计同一攻击/质量层的上包络 `U_a`，再取预注册的 lower envelope：

```text
R_robust = quantile_a(C_a - U_a, q = 0.10)
```

推荐 raw route：

| 路由 | 条件 | 解释 |
| --- | --- | --- |
| `attack_stable_candidate` | 所有必要 attack pair 完整，`R_robust` 通过，multi-operator/view 无冲突，decoy/reference/null gate 通过 | 压力下仍有来源条件局部支持；只进入人工复核 |
| `attack_fragile_review` | 未攻击样本通过但一个或多个压力层发生方向反转、null envelope 超界或 provenance/watermark 冲突 | 证据不稳定，保留攻击审计 |
| `null_consistent` | 普通传播层在所有/大多数压力下与 null 一致 | 不能升级 candidate，也不等于人类创作 |
| `insufficient` | 授权、配对、digest、profile、mask、operator、攻击支持或删除状态失败 | fail-closed |

不得将 `R_robust` 转成 AIGC probability、作者、版权或法律字段；普通传播 scope 永远不能升级为 candidate。

### 7.4 最小对照和指标

同一冻结 manifest、同一候选 coverage、同一动作预算下比较：

1. PC-SCFT 无攻击；
2. PE-CEA ordinary-propagation envelope；
3. detector-only anti-forensics stress；
4. AR-SCMI 完整 paired attack/null。

分层覆盖 benign propagation、JPEG/resize/crop、神经压缩或截图模拟、授权的 fingerprint/watermark removal 输出、wrong-reference/decoy、known/unseen generator、next-time-window 和低质量样本。必须报告：

- ordinary-propagation FPR、reference false-match、attack route flip；
- risk@coverage、unknown/review coverage、attack-stable candidate recall；
- ROI IoU/Dice/boundary-F、mask-out/region-swap faithfulness；
- P50/P95、每千张成本、probe failure 和人工复核分钟。

### 7.5 证伪和撤回门

只有在相同 coverage/action budget 下，AR-SCMI 降低普通传播 FPR、错误 reference 或 attack route flip，且外部攻击/下一时间窗仍保持，才可讨论研究增量。出现以下任一情况即撤回算法创新主张，保留为 red-team/audit sidecar：

- 只增加 `unknown/review`，接受样本 risk 不下降；
- 只在已知 generator/IID 或未攻击数据上改善；
- 通过更高拒判或删掉缺失攻击样本获得“提升”；
- attack/null 依赖同一生成链，独立性无法审计；
- P95、成本、存储或人工复核分钟明显恶化；
- B/A、watermark/C2PA 或 deletion/authorization 任何失败仍能回退到 candidate。

### 7.6 实施顺序

这是阶段 7 离线研究候选，暂不改线上接口和 `aigc_result_v1`：

1. 等 `ALG-001` 真实 retrieval replay、G0–G6 和 `real_pc_scft_manifest_v1` 通过；
2. 先只接收外部授权 red-team artifact manifest，完成 attack pair/matched null/replay digest validator；
3. 复用 `PC-SCFT`、`PE-CEA`、`reference_specificity`、`invariant_effect` 的 raw output，不重新训练 detector；
4. 在同一 manifest 上完成四路消融和外部攻击/时间切分；
5. 只有研究评审通过后，才讨论是否登记新的决策和技术契约；否则删除 sidecar，保留原有源代码和验证记录。

## 8. 对当前项目的实际建议

- 主算法叙事继续使用“来源条件、可回放、可拒判的局部编辑风险筛查”，不要使用“解决 AIGC”“准确识别人类/AI”或“自动版权确权”。
- 把 detector、generator fingerprint、C2PA/watermark、asset registry 和 legal review 分开存储；跨层冲突只进人工复核。
- 先完成阶段 1–5 的无假成功、身份/上传安全、EvidenceV1、真实评测和可复现部署门；AR-SCMI、SIPA、DRCS 和商业 sidecar 都不能提前接线上。
- 商业试点优先验证私有 DAM/MAM 的 `metadata_mutation_guard + provenance_conflict_replay + Review Workbench`；AI Act/C2PA 只能作为字段与回放适配需求，不能当销售承诺。
