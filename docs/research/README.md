# 外部研究资料入口

本目录只保存一手来源索引和核验规则，不保存第三方图片、受限模型权重、客户材料或未经授权的原始数据。

## Agent 使用顺序

1. 先读根目录的 `AGENTS.md` 和 `docs/00-当前任务说明.md` 至 `docs/04-实施方案.md`。
2. 需要外部依据时，再读 [外部证据索引](外部证据索引.md)，按政策/标准、市场采购、竞品、算法论文定位来源。
3. 论文或网页只能支持“设计约束、竞争事实或研究假设”；项目效果必须回到 `docs/07-验证与运行记录.md`，并附 manifest、profile 和 runner digest。
4. 新增来源时记录 URL、来源等级、核验日期、可迁移主张和不可外推内容；失效链接或版本变化先改索引，再改 `docs/01`、`docs/05` 或 `docs/06`。

## 目前最重要的研究边界

- 现有官方云服务已经覆盖通用 AIGC 检测、隐式标识和局部篡改/编辑区域；Smart Shadow 不把单一分类器或热力图作为独立壁垒。
- 当前可辩护的创新候选是：登记原件、同传播族无编辑 counterfactual、同坐标帧区域配准、质量/传播族 null 校准、patch 形状路由和证据不足拒判的组合协议。
- 论文、标准和采购公告不能证明本仓库已经具备真实模型效果、客户、收入、合规认证或部署能力。

## 证据等级

`A` 表示法律/标准/政府或正式会议论文，`B` 表示官方产品/评测/数据集页面，`C` 表示预印本或厂商自报材料。等级越低，越需要在项目内独立验证；所有等级都不能替代真实授权图片和客户验收。
